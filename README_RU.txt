Create: Aero Cables + Power Grid — форк с кабелем для Create: Power Grid
=======================================================================

СБОРКА (один раз, дальше только при изменениях)
-----------------------------------------------
1. Распакуй архив в папку БЕЗ русских букв в пути, например:  C:\mods\AeroCables-PowerGrid
   (в пути к "Документам" у тебя есть кириллица — Gradle и Java иногда на этом спотыкаются)
2. Двойной клик по  build-mod.bat
   - Первый запуск долгий (10–20 минут): Gradle скачает Minecraft, NeoForge, Create, Aeronautics и прочее (~2–3 ГБ).
   - Нужен JDK 21 (у тебя есть).
3. Когда напишет "Готово", откроется папка build\libs. Нужный файл:
       aerocables-0.4.0-powergrid.1.jar      (НЕ тот, что с -sources, если такой будет)
4. Если сборка упала — скопируй текст ошибки из окна и пришли мне.

УСТАНОВКА В СБОРКУ
------------------
- Удали из mods оригинальный Create: Aero Cables (aerocables-...jar) — этот файл его ЗАМЕНЯЕТ (тот же modid).
- Положи aerocables-0.4.0-powergrid.1.jar в mods. На сервер и всем игрокам.
- Нужен Create: Power Grid 0.6.x для NeoForge 1.21.1 (собрано под 0.6.2 — лучше его).
- Без Power Grid мод тоже запустится, просто кабеля Power Grid не будет.

КАК ПОЛЬЗОВАТЬСЯ В ИГРЕ
-----------------------
1. Как в обычном Aero Cables: поставь Cable Connector рядом с лебёдкой (Rope Winch) на одном конце троса
   и рядом с Rope Connector на другом.
2. Скрафти "Катушка кабеля Power Grid":  Cable Spool в центре + 4 Insulated Copper Wire (Power Grid) крестом.
3. ПКМ катушкой по первому коннектору, потом по второму. Коннекторы превратятся в
   "Коннектор кабеля Power Grid": два тонких провода (красный + и синий −) идут вдоль троса.
4. На каждом коннекторе две клеммы: красная (+) и синяя (−). Подключай к ним обычные провода Power Grid,
   можно любые (медные, изолированные, железные...). + одного конца соединён с + другого, − с −.
5. Сопротивление кабеля = длина × pgCableResistancePerBlock (по умолчанию 0.001 Ом на блок на каждый провод).
   Настраивается в  saves/<мир>/serverconfig/aerocables-server.toml

ЧТО ПОКА НЕ СДЕЛАНО (версия 1)
------------------------------
- Кабель не перегревается и не сгорает от тока (обычные провода Power Grid — сгорают).
- Тэги блока (быстро ломается киркой / "лёгкий" для массы корабля) не подхватываются — ломается рукой,
  весит как обычный блок. Причина: эти тэги генерируются датагеном, а Power Grid в датагене не загружен.
- Нет отдельной Ponder-сцены.
- Код писался без возможности собрать его у меня, поэтому первая сборка может выдать ошибку компиляции —
  пришли её, поправлю.
